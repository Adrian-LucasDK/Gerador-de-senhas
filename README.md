# 🔐 Gerador de Senhas Seguras

Aplicativo desenvolvido em Python com interface gráfica utilizando Tkinter, que permite gerar senhas aleatórias e seguras de acordo com as preferências do usuário.

## 🚀 Funcionalidades

- Geração de senhas aleatórias.
- Escolha do tamanho da senha.
- Inclusão de letras maiúsculas e minúsculas.
- Inclusão de números.
- Inclusão de caracteres especiais.
- Interface gráfica simples e intuitiva.
- Facilidade para copiar a senha gerada.

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter
- Secrets
- String

## 📋 Requisitos

- Python 3 instalado.
- Tkinter disponível na instalação do Python.

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd gerador-de-senhas
```

3. Execute o programa:

```bash
python gerador_senhas.py
```

## 📚 Objetivo

Projeto desenvolvido para praticar conceitos de Python, geração de números aleatórios seguros, manipulação de strings e desenvolvimento de interfaces gráficas.
